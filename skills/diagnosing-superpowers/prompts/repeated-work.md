维度：重复工作

找到会话中重复完成的工作。

1. 将每个工具调用提取为 `(行号, 轮次, 工具, 键)`，其中 `键` 是：读取/编辑/写入的文件路径；shell 调用的命令文本（去除尾部空白；保留完整命令）；子代理派发的 `description` 加上提示的前 80 个字符；搜索的查询。
2. 按 `(工具, 键)` 分组，并报告达到或超过阈值的组：

   | 类别 | 阈值 | 豁免 |
   |---|---|---|
   | 读取、搜索 | 3 | |
   | 编辑 | 2 | |
   | shell 命令 | 2 | 状态检查和测试运行（`git status`、`ls`、`pwd`、测试运行器） |
   | 子代理派发 | 2 次相同描述 | |
3. 对于每个组，检查重复之间是否有任何改变（对该文件的写入、压缩、人类修正）。说明是哪种情况；编辑后的重新读取不是发现，压缩后的重新读取是归因于压缩的发现，中间没有任何内容的重新读取是独立的发现。
4. 查找重新推导的决策：助手文本中得出的结论与会话中较早陈述的结论相同（相同的文件、相同的设计选择、相同的要运行的命令）。引用两处。
5. 每组一个发现，带有第一个和最后一个行号以及计数。
