# Pi 工具映射

技能以动作表述（"派发子代理"、"创建待办"、"读取文件"）。在 Pi 上，这些动作解析为以下工具。

| 技能请求的动作 | Pi 等效 |
| --- | --- |
| 派发子代理（`Subagent (general-purpose):` 模板） | 使用已安装的子代理工具，如 `pi-subagents` 提供的 `subagent`（如果可用） |
| 任务跟踪（"创建待办"、"标记完成"） | 使用已安装的待办/任务工具（如果可用），否则在计划或 `TODO.md` 中跟踪任务 |

## 子代理

Pi 核心不附带标准子代理工具。`pi-subagents` 包是一个强大的可选伴侣，提供具有单代理、链式、并行、异步、分叉上下文和恢复/状态工作流的 `subagent` 工具。如果没有子代理工具可用，不要伪造 `Task` 调用；在当前会话中顺序执行，或解释可选子代理功能未安装。

## 任务列表

Pi 核心不附带标准任务列表工具。如果安装了待办/任务扩展，使用其文档化的工具。否则使用 Superpowers 计划文件、Markdown 中的检查清单，或仓库本地的 `TODO.md` 进行任务跟踪。旧的 Superpowers 文档可能引用 `TodoWrite`；将其视为上述任务跟踪动作。
