# 技能设计的说服原则

## 概述

LLM 对与人类相同的说服原则做出反应。理解这种心理学帮助你设计更有效的技能——不是操纵，而是确保关键实践即使在压力下也被遵循。

**研究基础：** Meincke 等（2025）用 N=28,000 AI 对话测试了 7 个说服原则。说服技术使合规率增加一倍以上（33% → 72%，p < .001）。

## 七个原则

### 1. 权威
**是什么：** 对专业知识、凭证或官方来源的尊重。

**在技能中如何工作：**
- 命令式语言："YOU MUST"、"Never"、"Always"
- 不可协商的框架："No exceptions"
- 消除决策疲劳和合理化

**何时使用：**
- 执行纪律的技能（TDD、验证要求）
- 安全关键实践
- 既定的最佳实践

**示例：**
```markdown
✅ 在测试之前编写代码？删除它。重新开始。没有例外。
❌ 考虑在可行时首先编写测试。
```

### 2. 承诺
**是什么：** 与先前行动、声明或公开声明的一致性。

**在技能中如何工作：**
- 要求宣布："Announce skill usage"
- 强制明确选择："Choose A, B, or C"
- 使用跟踪：待办事项用于清单

**何时使用：**
- 确保技能实际被遵循
- 多步骤流程
- 问责机制

**示例：**
```markdown
✅ 当你找到技能时，你必须宣布："I'm using [Skill Name]"
❌ 考虑让你的合作伙伴知道你使用哪个技能。
```

### 3. 稀缺性
**是什么：** 来自时间限制或有限可用性的紧迫感。

**在技能中如何工作：**
- 时间绑定要求："Before proceeding"
- 顺序依赖："Immediately after X"
- 防止拖延

**何时使用：**
- 即时验证要求
- 时间敏感工作流
- 防止"我稍后做"

**示例：**
```markdown
✅ 在所有任务执行完成之后，立即请求整体代码审查，然后再合并。
❌ 你可以在方便时审查代码。
```

### 4. 社会证明
**是什么：** 符合他人所做或被认为是正常的事情。

**在技能中如何工作：**
- 通用模式："Every time"、"Always"
- 失败模式："X without Y = failure"
- 建立规范

**何时使用：**
- 记录通用实践
- 警告常见失败
- 强化标准

**示例：**
```markdown
✅ 没有待办事项跟踪的清单 = 步骤被跳过。每次都是。
❌ 有些人发现待办事项清单对清单有帮助。
```

### 5. 统一性
**是什么：** 共享身份、"我们感"、内群体归属。

**在技能中如何工作：**
- 协作语言："our codebase"、"we're colleagues"
- 共享目标："we both want quality"

**何时使用：**
- 协作工作流
- 建立团队文化
- 非等级实践

**示例：**
```markdown
✅ 我们是同事一起工作。我需要你的诚实技术判断。
❌ 你应该告诉我我是否错了。
```

### 6. 互惠
**是什么：** 回报收到的好处的义务。

**如何工作：**
- 少用 - 可能感觉操纵
- 技能中很少需要

**何时避免：**
- 几乎总是（其他原则更有效）

### 7. 喜欢
**是什么：** 偏好与我们喜欢的人合作。

**如何工作：**
- **不要用于合规**
- 与诚实反馈文化冲突
- 创建阿谀奉承

**何时避免：**
- 始终用于纪律执行

## 按技能类型的原则组合

| 技能类型 | 使用 | 避免 |
|------------|-----|-------|
| 执行纪律 | 权威 + 承诺 + 社会证明 | 喜欢、互惠 |
| 指导/技术 | 适度权威 + 统一性 | 重权威 |
| 协作 | 统一性 + 承诺 | 权威、喜欢 |
| 参考 | 仅清晰度 | 所有说服 |

## 为什么这有效：心理学

**明确规则减少合理化：**
- "YOU MUST" 消除决策疲劳
- 绝对语言消除"这是例外吗？"问题
- 明确的反合理化对策关闭特定漏洞

**实施意图创建自动行为：**
- 清晰触发器 + 必需操作 = 自动执行
- "当 X，做 Y" 比"通常做 Y" 更有效
- 减少合规的认知负荷

**LLM 是类人的：**
- 在包含这些模式的人类文本上训练
- 权威语言在训练数据中先于合规
- 承诺序列（声明 → 行动）经常建模
- 社会证明模式（每个人都做 X）建立规范

## 道德使用

**合法：**
- 确保关键实践被遵循
- 创建有效文档
- 防止可预测的失败

**不合法：**
- 为个人利益操纵
- 创建虚假紧迫感
- 基于内疚的合规

**测试：** 如果用户完全理解，此技术是否服务于用户的真正利益？

## 研究引用

**Cialdini, R. B. (2021).** *Influence: The Psychology of Persuasion (New and Expanded).* Harper Business.
- 七个说服原则
- 影响研究的经验基础

**Meincke, L., Shapiro, D., Duckworth, A. L., Mollick, E., Mollick, L., & Cialdini, R. (2025).** Call Me A Jerk: Persuading AI to Comply with Objectionable Requests. University of Pennsylvania.
- 用 N=28,000 LLM 对话测试 7 个原则
- 使用说服技术合规增加 33% → 72%
- 权威、承诺、稀缺性最有效
- 验证 LLM 行为的类人模型

## 快速参考

在设计技能时，问：

1. **它是什么类型？**（纪律 vs. 指导 vs. 参考）
2. **我试图改变什么行为？**
3. **哪个原则适用？**（通常权威 + 承诺用于纪律）
4. **我组合太多了吗？**（不要使用所有七个）
5. **这道德吗？**（服务于用户的真正利益？）
